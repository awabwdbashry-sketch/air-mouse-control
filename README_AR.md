# 🖱️ التحكم بالماوس عن طريق اليد

مشروع يعتمد على **رؤية الكمبيوتر (Computer Vision)** للتحكم في ماوس الكمبيوتر باستخدام حركات اليد التي يتم التقاطها من خلال كاميرا الويب.

يستخدم المشروع **MediaPipe** لتتبع نقاط اليد، و**OpenCV** لمعالجة الفيديو القادم من الكاميرا، بينما يتم استخدام **PyAutoGUI** للتحكم في مؤشر الماوس الحقيقي على الكمبيوتر.

## ✨ المميزات

* 🖐️ تتبع اليد في الوقت الحقيقي
* 🖱️ تحريك مؤشر الماوس باستخدام إصبع السبابة
* 👆 تنفيذ النقر باستخدام حركة اليد
* ✋ استخدام راحة اليد لإيقاف التحكم مؤقتًا
* 🎥 معالجة فيديو الكاميرا بشكل مباشر
* 🎯 حركة سلسة لمؤشر الماوس
* ⚡ استجابة سريعة لحركات اليد
* 💻 التحكم المباشر في ماوس النظام

## 🛠️ التقنيات المستخدمة

* 🐍 Python
* 👁️ OpenCV
* ✋ MediaPipe

* 🖱️ PyAutoGUI

## ⚙️ كيف يعمل المشروع؟

يبدأ المشروع بالتقاط فيديو مباشر من كاميرا الويب باستخدام OpenCV.

بعد ذلك يقوم **MediaPipe** باكتشاف اليد وتحديد مجموعة من نقاطها الرئيسية (Hand Landmarks).

يتم تحديد موقع إصبع السبابة وتحويل إحداثياته من مساحة الكاميرا إلى إحداثيات شاشة الكمبيوتر.

بعد ذلك يستخدم **PyAutoGUI** هذه الإحداثيات لتحريك مؤشر الماوس الحقيقي.

كما يتم التعرف على حركة **Pinch** بين الأصابع واستخدامها لتنفيذ النقر بالماوس.

أما حركة **راحة اليد المفتوحة** فتُستخدم لإيقاف التحكم بالماوس مؤقتًا.

## 🔄 آلية عمل المشروع

```text
كاميرا الويب
     ↓
OpenCV
     ↓
اكتشاف اليد بواسطة MediaPipe
     ↓
تحديد نقاط اليد
     ↓
التعرف على الإيماءات
     ↓
تحريك المؤشر / النقر
     ↓
ماوس الكمبيوتر
```

## 🖱️ التحكم بالماوس

| الحركة          | الوظيفة              |
| --------------- | -------------------- |
| ☝️ إصبع السبابة | تحريك مؤشر الماوس    |
| 🤏 Pinch        | تنفيذ نقرة بالماوس   |
| ✋ راحة اليد     | إيقاف التحكم بالماوس |

## 📦 التثبيت

قم بتحميل المشروع:

```bash
git clone https://github.com/awabwdbashry-sketch/air-mouse-control.git
cd air-mouse-control
```

أنشئ بيئة افتراضية:

```bash
python -m venv venv
```

قم بتفعيل البيئة الافتراضية في Windows:

```bash
venv\Scripts\activate
```

ثم قم بتثبيت المكتبات:

```bash
pip install -r requirements.txt
```
